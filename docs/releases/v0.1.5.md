# Commander's Table v0.1.5

Read another player's commander from their profile, with full card images and readable rules text. This release also makes Home settings easier to find and gives life controls cleaner circular feedback.

- **View commander:** tap a player's name/profile and choose **View commander** to see its full card, mana cost, type, rules and stats. Approved guests can read any player's commander without changing that player's editing permissions. The reader also works in one-device games.
- **Partners and card faces:** select either partner or switch between faces of a double-faced card. A saved card uses its selected printing; a commander name can be looked up without choosing background artwork first.
- **Readable fallbacks:** failed lookups offer a retry, and available rules text stays readable if the card image cannot load. Recently read card text can reopen from the current tab's memory for up to one hour during an outage; reloading clears that text cache. New lookups require a connection.
- **Clearer controls:** Home's **Display & browser settings** button has a more visible border, background and icon. Life-control press, hover and keyboard-focus feedback is circular and follows the player's color, while the existing large touch areas and hold behavior remain intact.
- **Correct request limits:** card lookups now return the intended 429 response when a request limit is reached, instead of an accidental 500 error. Artwork and full-card lookups share upstream data safely while validating their own responses.

Pull the update with `docker pull ghcr.io/addison16/commanders-table:latest`, then recreate the container using the existing Compose project, volume and public origin. Back up first. Saved games and room memberships remain compatible, with no game-save or SQLite schema change from v0.1.4. Browser clients should apply **Save & update** when prompted.
