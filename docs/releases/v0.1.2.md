# Commander's Table v0.1.2

Player dice now use their seat colors while keeping the rounded, polished pearl finish and upright numbers. **Utilities → Roll for** selects a player for ordinary dice and coins; shared guests default to their own seat. Rerolls, percentile pairs and saved roll replays keep the selected player. Each player's first-player d20 uses their color, including tie rerolls, without revealing the winner early.

The homepage symbol is now the consistent app logo, including the top-left banner, browser favicon and home-screen install icons.

This release also fixes:

- Reconnects that could return to a room after switching to local play.
- Concurrent saves that could lose recent-room entries, replace newer offline snapshots, or restore deleted archive entries.
- Player and counter forms showing stale values after live updates. Untouched fields now stay current, while unfinished edits are preserved.
- Expired guest memberships leaving stale seat availability on other phones.
- Recovery and local-game transitions retaining old room state or timer clock offsets.
- Duplicated browser tabs sharing an editing identity on browsers with Web Locks. Existing saved-game revision checks remain the fallback elsewhere.

Saved games, room memberships, storage identifiers and the database schema remain compatible. New dice-player metadata is optional; older rolls still display correctly.
