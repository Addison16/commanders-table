# Commander's Table v0.1.4

This release adds optional commander backgrounds, a single save for player edits, and dice that automatically follow the player’s chosen color.

- **Optional commander backgrounds:** choose a Scryfall name suggestion or paste a card link during setup, joining, or play. Partner commanders share the panel. Selected artwork follows approved seats, saved games and rematches, with artist credits and links to the cards. Viewed images can be cached for offline play; missing images or failed searches leave manual names and counters usable.
- **One Save changes button:** save a player's name, color and all commander names/artwork together. One Undo restores the whole edit, while recorded damage, cast counts and player identities remain intact. Drafts stay available when a save fails, is interrupted or times out, so you can retry.
- **Dice that follow the player:** local rolls default to the last player saved or selected and use that player's current color. Shared guests still default to their own seat. Choose **The table** for the original ivory dice.
- **Reliable storage failure handling:** an aborted browser storage transaction now reports the failure without an unhandled error, retaining edits for retry.
- **A consistent Docker install command:** the package page uses `docker pull ghcr.io/addison16/commanders-table:latest`. Version tags remain available for pinned installations.

Keep the existing Compose project, volume and public origin when updating, and back up first. Saved games and memberships remain compatible, with no SQLite schema change. Browser clients should apply **Save & update** when prompted. New commander metadata may require the pre-update backup when downgrading to an older app.
