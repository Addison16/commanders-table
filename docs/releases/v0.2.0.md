# Command Table v0.2.0

Command Table brings more of the table into one view: player-status badges, group life changes, commander rulings and shareable game recaps. It also makes starting another game and laying a phone between players simpler.

- **A new name:** Commander's Table is now **Command Table** in the app, browser, installable-app name and exports. The GitHub repository and Docker image remain at `commanders-table`, so existing installations keep their image address.
- **Fresh games and familiar rematches:** **New game** asks one phone or multiple phones, then starts with default players, colors, commanders and settings. **End game** offers **Rematch**, **End game** and **Cancel**. Rematch keeps the current profiles, partners, artwork and shared seats while restoring the configured starting life and clearing game stats. Names and commanders remain editable, and recently ended games remain recoverable for 24 hours.
- **Layouts that follow the phone:** phones and tablets use **Shared table** in landscape and **All facing me** in portrait by default. Each device keeps its own layout and a guest's **My seat** view. Choosing a layout or flipping a seat fixes the layout until **Follow device rotation** is enabled again. Held life controls stop before counters move; desktop layouts remain manual.
- **Group life changes:** choose a caster and affected active opponents in Utilities, enter the loss per opponent and optionally enter the caster's **total** gain. The caster is excluded from life loss, and gain is never guessed or multiplied. Preview the totals, then save the whole effect together; one Undo reverses it. In shared rooms this action belongs to the host. Changed games, invalid totals and uncertain saves require review before another effect can be submitted.
- **Commander rulings:** **View commander → Rulings & notes** loads dated card-specific rulings with Wizards of the Coast or Scryfall attribution. Failed lookups can be retried independently. Recently read rulings remain available in the current tab for up to one hour during an outage; reload clears that cache.
- **Shareable game recaps:** **Game menu → Share game recap** creates a PNG with player names, colors, commanders, life totals and duration. Share it through supported native share controls or download it. Active games are labeled **In progress**; final recaps offer an optional winner or draw that changes only the exported image. Open **View final game** from Home to make a final recap.
- **Status at a glance:** compact **CMD MAX**, **POISON** and **TAX** badges appear when values are present. Commander damage shows the highest total from one commander, and partners keep separate **TAX I/II** values. Zero values and disabled trackers stay hidden; warnings follow the configured thresholds.
- **Safer interrupted edits:** dismissing a save-error notice keeps the editor and draft open. Group effects wait for durable storage or a room acknowledgement, protect against duplicate application after reconnecting, and require checking totals after an uncertain save. Stale end/rematch prompts cannot change a replacement game opened in another tab.
- **Docker installation and updates first:** the README, hosting guide and release instructions now lead with published Compose files and `latest`. Hardware setup, health checks, backups, restoration and updates all keep the hosted app in Docker. Pulling an image downloads it; recreating the container applies it.

Existing local saves and room memberships remain compatible; this update does not reset games or change the SQLite schema. Keep the same Compose project, data volume, configuration and public origin, and back up before updating. Browser clients should apply **Save & update** when prompted. Backup payload identifiers are unchanged, so exports using the previous app name remain supported.

Local validation passed 172 unit/integration checks and 130 Chromium/WebKit browser cases, with two expected skips, plus production update/offline, HTTPS/WSS, LAN and x64 container checks. The dependency audit reports no known vulnerabilities. Live updates preserved saved games, and offline badge/Undo, group effects, actual Scryfall rulings and recap PNG export were checked. Before publication, the release workflow verifies the complete browser suite, production PWA update/offline behavior, HTTPS/WSS proxy behavior and native amd64/arm64 containers. Physical-phone and native share-sheet behavior remain unverified.
