# Commander's Table v0.1.0

The first public release of a mobile-friendly Magic life counter for one shared phone or a hosted room with individual phones.

- One to eight players, life and poison counters, commander damage, partner commanders, and command-zone cast counts.
- Shared rooms with code/link/QR invitations. Joining players choose their own name and commanders; the host approves their seat.
- Rounded ivory dice roll over the board, with sound, readable results, and tied d20 rerolls for choosing the starting player.
- A shared-table layout for a phone placed sideways between players, optional turn tracking, and undo/history.
- Browser saves, recent games, export/import, and 24-hour recovery after accidentally ending a game.
- Docker images for `linux/amd64` and `linux/arm64`, with persistent SQLite storage.

Release verification covers types, lint, domain/storage/server tests, Chromium and WebKit, offline/update behavior, HTTPS/WSS, and native container start/join/update/restart/backup checks on both architectures. Physical iPhone/Android validation remains unverified.

When upgrading from a development build, back up the server's SQLite volume first and keep the same Compose project name, volume, and public origin. This version uses database schema 2; older schema-1 builds require a matching pre-upgrade backup if rolled back.
